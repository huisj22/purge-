## v0.2 — 配置中心与规则技能中心

- 配置中心：多目标（宿主/自身）+ diff/history/冲突检测 + 预演
- 规则中心：多槽位、作用域（全局/项目/会话）、导入导出
- 技能中心：frontmatter 校验、依赖检查、导入安全检查、可用性诊断
- 插件体系：清单/权限/健康检查/示例插件（把演练台能力以插件形式提供）

## v0.3 — 事务式宿主维护

- `install --verify-first`：先验证再允许关闭进程
- 归档换包（可选、默认关）：独立原生助手、argv 数组传参、显式 Job Object
- 更新中心：离线 release index + SHA256 + 分阶段 + 回滚

## v1.0 — 多宿主与治理

- 第二宿主适配器（任一 CLI Agent 宿主）验证 Adapter 抽象
- 策略模板与团队策略分发（只读 + 签名）
- 可观测性：跨宿主时间线、失败聚类、成本（数据可得时）

## 明确延后/不做

| 项 | 原因 |
| --- | --- |
| 自动关闭/重启宿主进程 | 高风险、可把用户机器停成半装；用户可手动重启 |
| 内置「解除审批/沙箱/提示词」的规则 | MASTER PROMPT §07 明确不作为目标 |
| 云端多租户 | 与单机运维定位冲突 |
| 红队演练台（1 MB） | v0.2 作为插件示例再引入，避免负担进核心 |
